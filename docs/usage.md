# 使用指南

本文说明 CVTranslate 的具体操作与限制。项目定位和快速开始见 [README](../README.md)。

## 1. 翻译工作台

### 亮色与暗色模式

点击右上角 GitHub 按钮左侧的月亮 / 太阳按钮切换主题。默认为亮色，不跟随系统自动切换。选择会记在当前浏览器、当前服务地址中，刷新后恢复；不影响翻译内容、历史或未保存的设置。浏览器禁止本地存储时仍可切换，但无法记住选择。

### 自动翻译与默认设置

- 输入或粘贴文本后，停止输入约 600 毫秒，或输入框失去焦点时，自动发起翻译；中文输入法组词期间不会提前提交。
- 更改语言、翻译服务或提示词模板，也会翻译当前文本。调用是否收费取决于所选服务。
- 自动中英互译采用简单规则：包含汉字时译为英文，否则译为简体中文。这不是完整的多语言检测，混合文本建议手动选择方向。
- 选择自动源语言时，目标语言会同时切换为自动，之后仍可手动指定目标语言。
- 在工作台切换服务会保存为应用默认服务，同时影响后续工作台会话和全局快捷键；离开页面不会中断这次保存，保存失败会提示且不自动重试。
- 工作台临时选择的语言和模板不会修改设置页中的默认值。打开历史任务或初始化时选择备用服务，也不会覆盖默认设置。
- 打开历史任务、切换显示模式不会重新提交翻译。失败请求不自动重试，也不自动切换供应商。

继续编辑时，应用会尽力取消已被替代的工作台任务，但取消无法撤回上游已经收到的文本或已经产生的费用。

### Markdown 编辑与显示

原文和译文默认以 Markdown 方式呈现，原文可直接进行富文本编辑。两侧标题栏的模式切换联动，可同时切换到源码模式查看或编辑 Markdown 文本。

- 从纯文本剪贴板、明确的 `text/markdown` 内容，或带有 Cursor / VS Code Markdown 元数据的复制内容粘贴时，会导入标题、列表和强调等结构，而不是把所有标记转义为普通文字。
- 其他富文本和编辑器内部复制内容保留正常粘贴行为。不支持的 Markdown 保留为文字，不执行 HTML，也不加载远程图片。
- 已有转义字符和代码块保持字面含义。粘贴不会重写历史记录。
- 复制和历史记录保存的是 Markdown 文本，不是 HTML。富文本编辑可能规范化 Markdown 排版；需要精确保留源格式时，请使用源码模式。
- 仅切换模式或载入历史任务，不会重写原文或重新翻译。

长文本会自动采用更紧凑的排版。以较长一侧的 Unicode 字符数计算，包含 Markdown 标记和空白：不超过 3,000 字符时正文为 16px，超过 3,000 时为 14px，超过 10,000 时为 12px；代码和源码分别为 14/13/12px。正文行高分别为 24/21/18px，两侧保持同一档位，标题保留层级。删除内容后会恢复较大字号。这只影响内容显示，不修改文本、设置或请求。

## 2. 翻译服务与提示词

### 内置 Microsoft Translator

新安装默认启用，不需要填写 API Key、服务地址、模型或提示词。升级时仅补全空的默认服务，不覆盖已有服务选择。Microsoft Translator 不使用 AI 提示词或人物风格。

内置 Microsoft 翻译和 Edge 朗读使用消费级服务接口，不是具有服务承诺的 Azure 合同服务。接口可能限流、变更或停止，不能据此承诺永久免费、不限量或持续可用。使用、分发或依赖这些集成前，请核对微软的适用服务条款。

### OpenAI 兼容服务

添加服务时，配置 API 基础地址、模型、按服务要求填写的 API Key，以及超时时间。例如基础地址可为 `https://api.openai.com/v1`。

新配置预填模型名 `gpt-6-luna`，这只是应用默认值，不代表你的服务一定提供该模型；请改为所用服务实际支持的模型。已有模型配置不会被升级覆盖。

连接测试会发送真实请求，可能计费；启动应用和普通保存不会自动测试连接。API Key 保存于 Windows 凭据管理器或 macOS 钥匙串，不写入历史数据库或 API 响应。

地址支持 HTTP 和 HTTPS，但 HTTP 会明文传输文本和可能携带的 API Key。建议使用 HTTPS。地址不能包含用户名密码、查询参数或片段；改变主机或协议后，不能静默复用原密钥。

### 提示词与人物风格

内置「通用翻译」模板为只读，默认包含 `Serious Developer` 人物风格，强调准确、中立、简洁和常用措辞。需要修改或移除风格时，复制内置模板再编辑副本；自定义人物描述最多 4,000 字符。

- 人物风格用于调整语气，不应改变原意、事实、请求和重要约束，也不覆盖目标语言选择。
- 内置模板要求 AI 只翻译代码之外的自然语言，尽量保留代码块、行内代码及可识别的未围栏代码，包括注释、字符串、标签和空白。纯代码应保持原样，不额外添加围栏。
- 代码保留优先于风格和目标语言指令，但这只是模型提示，不是本地代码解析或逐字节保真保证，也不适用于 Microsoft Translator。重要内容需人工核对。
- 已有自定义模板不会自动获得新版规则；需要时重新复制内置模板或手动补充。
- 风格会增加输入 token，但不会因此额外发起一次模型调用，也不会增加自动重试。
- 「渲染预览」只在本地展示组合后的提示词，不调用模型。历史任务保存当时的提示词和风格快照，之后修改模板不会改写旧记录。

可在工作台选用副本，也可在设置中设为默认模板，供全局快捷键使用。工作台优先选择已配置的默认服务和模板，不可用时回退到可用项目。

## 3. 历史记录与用量

成功结果会在请求上游前参与复用。原文必须完全相同，同时匹配语言方向、服务实例、接口地址、模型，以及适用的提示词内容和人物风格。

- 命中时显示复用状态，不访问供应商、不新增 token 用量。
- 复用在重启后仍然有效，也适用于剪贴板快捷键；每次操作仍有独立的本地任务和粘贴结果。
- 失败、取消或中断的任务不参与复用。删除所有匹配历史后，就无法再复用该结果，没有额外持久化缓存。
- 历史读取或保存失败时会报错，而不是绕过错误悄悄发起可能计费的新请求。
- 历史记录支持分别复制原文和译文。清空历史需要确认，也会删除相应的复用数据和用量统计来源。

当 OpenAI 兼容服务返回标准用量字段时，记录输入、输出和总 token 数。「Token 报表」提供最近 365 天热力图、今日 / 近 7 天 / 近一个月汇总及按日明细，按浏览器本地时区统计。

日明细只列出有记录的日期，按时间倒序、每页 10 条；翻页不影响汇总和热力图。供应商未返回的用量不估算，失败任务不计入，不将 token 换算为金额。此报表不是供应商账单。

## 4. 朗读与语音试听

在「应用设置 > 朗读」中选择引擎，为英文和简体中文分别设置语音，再保存。引擎选择独立于翻译服务，两种引擎分别保留各自的语音设置。

- **Edge 在线朗读**：由本地服务把要朗读的文本发送给微软，获取 MP3 后播放。不需用户填写密钥，但内部使用临时授权令牌，并非完全无认证接口。可选语音来自应用内维护的列表，不是微软全部实时语音；默认英文和中文语音分别为 Andrew Multilingual 和 Xiaoxiao Multilingual。
- **Web Speech API**：调用当前浏览器和操作系统提供的语音。列表可能异步加载，也可能因设备而不同。默认选项匹配语言；指定语音失效时需重新选择，不会静默替换。此模式不经过应用的 Edge 合成接口，但语音本身仍可能依赖联网服务，不能等同于离线。

点击语言旁的「试听」会使用当前未保存的引擎和语音朗读固定示例，不读取工作台内容，也不保存草稿。再次点击可取消或停止；开始另一个试听、切换引擎或语音、刷新浏览器语音、离开朗读设置页都会停止试听。Edge 试听仅向微软发送固定示例，浏览器试听也可能联网。仅选择语音或保存设置不会自动播放。

工作台朗读需要主动点击对应一侧的朗读按钮，每次以点击时的文本和语言为准：

- 自动语言根据是否包含汉字选择中文或英文，不是完整的多语言检测。
- 最多接受 20,000 字符，浏览器还可能施加更小限制。Edge 会依次合成长文本的分段，全部完成后才开始播放。
- 再次点击正在工作的按钮可取消加载或停止播放。
- 翻译状态变化、任务切换、编辑或清空当前文本和语言不会打断已开始的这次朗读。
- 开始另一侧朗读、更改已保存的朗读设置、离开工作台会停止播放；刷新未改变的设置不会。
- 音频和临时令牌不持久化。失败会显示错误，不自动重试或切换引擎。

## 5. 全局复制快捷键

仅处理用户明确复制的文本，不会因为选中文本就发起翻译，也不会持续采集剪贴板。

- **Windows**：连续按 `Ctrl+C` 三次，翻译后直接粘贴；四次，翻译后打开结果页面，不粘贴。
- **macOS**：对应 `Command+C` 三次和四次。
- 这些复制手势固定，不能在设置中改绑或关闭。「仅打开管理界面」是独立的可配置快捷键，不能设置为普通的 `Ctrl+C` 或 `Command+C`。

> **三次复制存在误粘贴风险。** 翻译完成后，会向当时的活动窗口发送粘贴，不校验原窗口、光标、选区或可编辑状态。中途切换应用可能把内容粘贴到错误位置。这是未经目标验证的实验性行为；需要自己确认结果时，优先使用四次复制。

可以按住 Ctrl / Command 连按 C，也可以每次完整按下并松开组合键。相邻按键间隔不超过 500 毫秒，完成后停顿 500 毫秒；只触发准确次数，四次不会同时触发三次动作，长按自动重复不计数。普通复制仍传给前台应用。

其他按键或识别手势期间的前台窗口变化会取消手势。最后一次复制后必须观察到新的剪贴板版本，否则不会提交旧文本。任务取消、剪贴板被其他操作改写或修饰键未释放，仍会阻止直接粘贴；敏感或密码来源也有拒绝机制。

粘贴后，译文保留在剪贴板中，不恢复原有富文本格式。应用不会自动按 Enter、全选、强制聚焦或提权。发出粘贴操作不代表目标软件已经接受内容。

除上述明确的三次复制例外外，受保护粘贴仅在能确认目标和剪贴板未改变时尝试。Windows 支持部分 Edit / RichEdit 和符合条件的 UI Automation 控件，macOS 依赖可访问性暴露的可编辑目标。不能据此承诺兼容所有浏览器、Electron 或自定义编辑器；不确定时需要手动复制。

### macOS 权限

全局手势需要「辅助功能」和「输入监控」权限。应用只检查状态，不会自动申请或弹出授权窗口。需要时由用户到「系统设置 > 隐私与安全性」为运行中的应用授权，再重启应用。

缺少权限或监听初始化失败时，全局快捷键不可用，但 WebUI 仍可使用。菜单栏的打开页面与退出功能不要求这两项权限。macOS 原生编译、权限与真实应用交互仍需在 Mac 上验证，Windows 检查不能替代。

## 6. 设置、后台运行与退出

设置分为翻译、朗读、快捷键、本地服务和版本。跨标签页切换保留草稿，不自动保存；有改动时才出现保存和放弃按钮。保存应用所有标签页的改动，放弃则恢复所有已保存设置。清空历史是独立的确认操作，不受保存或放弃草稿控制。

「版本」显示当前版本和 GitHub 仓库地址。点击「检查更新」才会访问 GitHub 查询最新发布版本，启动或打开页面时不会自动检查。有新版本时显示「更新」，点击后在浏览器打开对应发布页，需手动下载替换。无法连接 GitHub、超时或被限流时显示检查失败，仍可通过仓库链接手动查看。开发版本无法与发布版本比较。

关闭浏览器不会退出后台程序。再次运行应用会打开已有实例的管理页面：

- Windows 可点击通知区域的 CVTranslate 图标，或右键选择「打开管理界面」「退出」。找不到图标时检查任务栏隐藏图标区域。
- macOS 使用菜单栏的 CVTranslate 图标，提供相同操作。
- 退出会取消待处理任务、注销快捷键并关闭本地服务，不删除设置或历史。管理页面没有应用退出按钮。

应用升级后应退出并重新启动后台程序，再刷新页面；只刷新 WebUI 不会载入新的 Go 后端行为。升级不需要通过清空数据库或浏览器数据来完成。

## 7. 数据、隐私与安全

- 默认管理地址是 `http://127.0.0.1:19327`。仅监听本机，校验 Host、Origin 和 Fetch Metadata；这些检查不等于用户身份认证。同机能够访问该端口的其他用户或进程也可能读取历史、修改设置和调用操作，**不要暴露或转发此端口**。
- 原文会在自动翻译触发时发送给所选服务；Edge 朗读则在明确点击后发送对应文本。应用没有账号服务、遥测或云同步，但这不代表翻译内容不出本机。
- API Key 使用系统凭据存储。历史是本地**未加密文本**，不是保密保险箱；请勿输入不允许外发或留存的内容。
- 日志位于 Windows 的 `%APPDATA%/CVTranslate/application.log` 或 macOS 的 `~/Library/Application Support/CVTranslate/application.log`，按设计不记录原文、译文和密钥。提交问题前仍应检查附件，不要上传数据目录、数据库、凭据或 `.env`。
- HTTP 接口地址不加密传输，应优先使用 HTTPS。应用不进行自动供应商重试或故障切换。
